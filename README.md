# Koodipaja-sivusto

Harjoitustyö: oma verkkosivusto HTML:llä ja CSS:llä.

## Sivuston aihe

**Koodipaja Oy** – kuvitteellinen verkkosivujen suunnittelu- ja ohjelmistoyritys,
joka tekee verkkosivuja, verkkokauppoja ja räätälöityjä ohjelmistoja pienille
ja keskisuurille yrityksille.

## Sivusuunnitelma

| Sivu | Sisältö |
|------|---------|
| index.html | Etusivu – esittely, palvelut korteissa, esittelyvideo ja tunnusääni |
| palvelut.html | Palvelut korteissa sekä hinnastotaulukko |
| referenssit.html | Toteutettuja projekteja kuvakortteina |
| yhteys.html | Yhteystiedot ja yhteydenottolomake |

## Työn eteneminen

- [x] Vaihe 1: aihe, sivusuunnitelma, kansiorakenne, ensimmäinen HTML-sivu
- [x] Vaihe 2: ulkoinen CSS, värit, fontit, välit ja semanttinen rakenne
- [x] Vaihe 3: layout (Grid ja Flexbox), kaikki neljä sivua ja navigaatio
- [x] Vaihe 4: kuvat, video ja ääni sekä position
- [x] Vaihe 5: hinnastotaulukko (caption, thead, tbody, tfoot) ja yhteydenottolomake
      (text, email, tel, number, date, select, textarea, radio, checkbox + validointi)
- [ ] Vaihe 6: responsiivisuus, pseudoluokat, validointi, saavutettavuus ja itsearviointi
