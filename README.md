# Koodipaja-sivusto

Harjoitustyö: oma verkkosivusto HTML:llä ja CSS:llä.

## Sivuston aihe

**Koodipaja Oy** – kuvitteellinen verkkosivujen suunnittelu- ja ohjelmistoyritys,
joka tekee verkkosivuja, verkkokauppoja ja räätälöityjä ohjelmistoja pienille
ja keskisuurille yrityksille.

## Sivusuunnitelma

| Sivu | Sisältö |
|---|---|
| `index.html` | Etusivu – yrityksen lyhyt esittely ja palvelut pääpiirteittäin |
| `palvelut.html` | Tarkempi kuvaus palveluista sekä hinnasto |
| `referenssit.html` | Esimerkkejä toteutetuista projekteista kortteina |
| `yhteys.html` | Yhteystiedot ja yhteydenottolomake |

## Kansiorakenne

```
koodipaja/
├── index.html
├── palvelut.html
├── referenssit.html
├── yhteys.html
├── css/
│   └── styles.css
└── images/
```
